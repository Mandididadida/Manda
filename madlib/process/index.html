Mad Lib Redesign Process

For my extra credit studio project, I am redesigning my Mad Lib project to improve its mobile usability, visual style, and story concept.

Project Focus

My selected studio project is my Mad Lib project. The current version works mainly as a desktop experience, so one of my main goals is to create a stronger mobile version. I also want to revise the story and visual direction. The original project felt too dark, and the story felt strange without a clear emotional purpose. For the redesign, I want the experience to feel more nostalgic and dreamlike, as if the user is reading a letter from a pen pal or a friend they have not seen for a long time.

Visual Design Direction

The improved visual design uses a softer and more dreamy atmosphere. Instead of relying on a dark background, I want the new version to use lighter colors, letter-inspired imagery, and a more emotional memory-based theme. My goal is to make the desktop and mobile versions feel visually connected, so the user experiences the same mood across both screen sizes.

Usability Test Plan

Since my major focus is UX/UI, I created a usability test to understand how general users experience the project. I chose users without UI/UX backgrounds because this project is intended for a general audience, not only designers. I want to see whether the project feels clear, readable, and easy to complete for people who are unfamiliar with the interface.

  1. Open the Mad Lib project on desktop.
  2. Read the instructions and explain what they think the project asks them to do.
  3. Fill in all required word input fields.
  4. Submit the form and read the final generated letter.
  5. Open or view the mobile version of the project.
  6. Describe anything that feels confusing, difficult, or unclear.

Interview Questions

  • Was the purpose of the project clear when you first opened it?
  • Were the instructions easy to understand?
  • Was the word input process easy to complete?
  • Did the mobile version feel comfortable to use?
  • Was the final generated story easy to read?
  • Did the visual style match the nostalgic letter or memory theme?
  • What part of the project would you change or improve?

User Testing Results

User Background Device Tested Key Feedback
User 1 Friend, no UI/UX background Desktop The concept was understandable, but the opening instructions could be more direct and easier to scan.
User 2 Friend, no UI/UX background Mobile The dreamy visual style felt interesting, but the input boxes needed more spacing and stronger contrast on a small screen.
User 3 Friend, no UI/UX background Desktop and mobile The letter concept felt more memorable than the original dark story, but the final result page needed better readability.

What I Learned

From the usability testing, I learned that the redesign needs to focus on clarity, readability, and mobile comfort. Users understood the general idea of the Mad Lib project, but some of them wanted clearer instructions before beginning the activity. The mobile version also needs larger input areas, more spacing, and stronger contrast so the form is easier to complete on a small screen. The feedback also showed that the nostalgic letter concept is stronger than the original strange story because it gives the project a more meaningful emotional direction. However, the dreamy background should not interfere with the readability of the text. Based on this feedback, I plan to revise the instructions, improve the mobile layout, increase the contrast of the input fields, and make the final generated letter easier to read.
